# NexaFlow AI Website

A responsive, single-page B2B AI solutions website inspired by the structure and messaging patterns in the supplied reference.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static server.

## Included
- Responsive navigation and hero section
- AI solution cards
- Industry tabs
- Benefits/outcomes
- Metrics
- Monthly/annual pricing toggle
- Comparison table
- Testimonials
- Book-a-demo form
- FAQ accordion
- Responsive mobile layout

Replace the placeholder company name, email, logos, testimonials, pricing and form handler before production.
